# ⚙️ Data Extraction Engine

> Enterprise-grade web scraping platform built using **Spring Boot**, **Jsoup**, and **TailwindCSS** for intelligent media extraction, structured parsing, and real-time analytics visualization.

---

## ✨ Core Features

- Intelligent image extraction with HD prioritization
- Video and hyperlink scraping
- Real-time analytics dashboard
- Extraction history monitoring
- Responsive dashboard architecture
- Structured media parsing
- Duplicate asset filtering
- Lazy-loaded image handling

---

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| ☕ Java | Backend Development |
| 🌱 Spring Boot | Application Framework |
| 📄 Jsoup | HTML Parsing & Data Extraction |
| 🎨 TailwindCSS | UI Framework |
| ⚡ JavaScript | Dynamic Frontend Logic |

---

## 📊 System Architecture

### 🔍 Advanced Media Parsing

The scraping engine intelligently extracts and filters:

- Images
- Videos
- Hyperlinks

Additional parsing capabilities include:

- `srcset` prioritization
- lazy-loaded media detection
- duplicate elimination
- structured URL normalization

---

### 📈 Real-Time Analytics

The analytics subsystem provides:

- scrape activity monitoring
- asset count aggregation
- historical extraction tracking
- total data point analysis

## ⚙️ Installation & Setup

### 1️⃣ Clone Repository

```bash
git clone https://github.com/Shahil-147/data-extraction-engine.git
```

---

### 2️⃣ Navigate to Project

```bash
cd data-extraction-engine
```

---

### 3️⃣ Run Application

```bash
mvn spring-boot:run
```

---

### 4️⃣ Access Dashboard

```txt
http://localhost:8181
```
